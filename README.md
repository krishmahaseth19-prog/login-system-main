# 🔐 Login Authentication System

A secure authentication system built with Node.js, Express.js, MongoDB Atlas, JWT, and bcrypt.

## Features

- User Registration
- User Login
- Password Hashing using bcrypt
- JWT Authentication
- Protected Dashboard
- Logout
- MongoDB Atlas Integration

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcrypt
- EJS
- CSS

## Installation

```bash
git clone https://github.com/ananya-adhikary07/login-system.git

cd login-system

npm install
```

Create a `.env` file:

```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Run the project:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
